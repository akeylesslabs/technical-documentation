Secure Remote Access (SRA) Admin Guides provide operational guidance for administrators who configure resource access, CLI workflows, and session controls.

Use this page as the entry point for administration tasks after baseline SRA deployment.

## Start Here by Admin Objective

Use this path based on the immediate objective:

1. Session visibility, recording, and forwarding: [Session Management](https://docs.akeyless.io/docs/sra-session-management)
2. Resource onboarding by target type: [Supported Resource Types](https://docs.akeyless.io/docs/sra-resource-types)
3. CLI-based access from local environments: [Akeyless Connect](https://docs.akeyless.io/docs/sra-akeyless-connect)
4. Secure file transfer operations: [Akeyless SCP](https://docs.akeyless.io/docs/sra-akeyless-scp)
5. SSH certificate-based access setup: [SSH Certificates](https://docs.akeyless.io/docs/sra-ssh-certificates)

## Documentation Map

Use this map to move through the SRA admin documentation by workflow:

* Session operations and audit controls: [Session Management](https://docs.akeyless.io/docs/sra-session-management)
* Resource-specific configuration: [Supported Resource Types](https://docs.akeyless.io/docs/sra-resource-types)
* CLI connection workflows: [Akeyless Connect](https://docs.akeyless.io/docs/sra-akeyless-connect)
* Secure copy workflows: [Akeyless SCP](https://docs.akeyless.io/docs/sra-akeyless-scp)
* SSH certificate configuration: [SSH Certificates](https://docs.akeyless.io/docs/sra-ssh-certificates)
