Secure Remote Access (SRA) Admin Guides provide operational guidance for administrators who configure resource access, entitlement policy, session controls, and CLI workflows.

Use this page as the entry point for administration tasks after baseline SRA deployment.

## Start Here by Admin Objective

Use this path based on the immediate objective:

1. Access policy, entitlement, and security controls: [Access Configuration and Policies](https://docs.akeyless.io/docs/sra-access-configuration-and-policies)
2. Session visibility, recordings, and runtime monitoring: [Session Management](https://docs.akeyless.io/docs/sra-session-management)
3. Runtime topology, scaling, and storage planning: [Infrastructure and Capacity Planning](https://docs.akeyless.io/docs/sra-infrastructure-and-capacity-planning)
4. Session reliability diagnostics and migration planning: [Troubleshooting and Migration](https://docs.akeyless.io/docs/sra-troubleshooting-and-migration)
5. Integrations and automation workflows: [Integrations and Automation](https://docs.akeyless.io/docs/sra-integrations-and-automation)
6. Resource onboarding by target type: [Supported Resource Types](https://docs.akeyless.io/docs/sra-resource-types)
7. CLI-based access from local environments: [Akeyless Connect](https://docs.akeyless.io/docs/sra-akeyless-connect)
8. Secure file transfer operations: [Akeyless File Transfer](https://docs.akeyless.io/docs/sra-akeyless-scp)
9. SSH certificate-based access setup: [SSH Certificates](https://docs.akeyless.io/docs/sra-ssh-certificates)
