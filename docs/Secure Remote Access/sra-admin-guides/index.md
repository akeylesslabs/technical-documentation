Configure Secure Remote Access (SRA) Guides provide operational guidance for administrators who configure resource access, entitlement policy, session controls, and CLI workflows.

Use this page as the entry point for administration tasks after baseline SRA deployment.

## Start Here by Admin Objective

Use this path based on the immediate objective:

1. Access policy, entitlement, and security controls: [Access Configuration and Policies](https://docs.akeyless.io/docs/sra-access-configuration-and-policies)
2. Session visibility, recordings, and runtime monitoring: [Session Management](https://docs.akeyless.io/docs/sra-session-management)
3. Runtime topology, scaling, storage planning, and troubleshooting: [Infrastructure and Capacity Planning](https://docs.akeyless.io/docs/sra-infrastructure-and-capacity-planning)
4. Integrations and automation workflows: [Integrations and Automation](https://docs.akeyless.io/docs/sra-integrations-and-automation)
5. Resource onboarding by target type: [Supported Resource Types](https://docs.akeyless.io/docs/sra-resource-types)
6. CLI-based access and secure file transfer from local environments: [Akeyless Connect](https://docs.akeyless.io/docs/sra-akeyless-connect)
7. SSH certificate-based access setup: [SSH Certificates](https://docs.akeyless.io/docs/sra-ssh-certificates)
