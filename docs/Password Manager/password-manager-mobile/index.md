Akeyless Password Manager for iPhone and Android puts your Akeyless vault in your pocket.
Browse your personal and corporate items, copy a password, add a new login, and fill saved
logins into Safari, Chrome and other apps with your phone's own AutoFill.

![The Corporate area on Android](https://files.readme.io/2b0f63a192c315e119a025849a052c61d65fd3fcd42d38923511990dda3864cd-vault-corporate.png)
*The Corporate area, with the tab bar along the bottom*

## Download

| Platform | Get the app | Requires |
|---|---|---|
| **iPhone** | [Akeyless Password Manager on the App Store](https://apps.apple.com/app/akeyless-password-manager/id6821884962) | iOS 15.0 or later |
| **Android** | [Akeyless Password Manager on Google Play](https://play.google.com/store/apps/details?id=com.akeyless.passwordmanager) | Android 7.0 or later (AutoFill needs 8.0) |

The app is free. You need an Akeyless account to sign in — there is no sign-up inside the
app. See [Installing the Mobile App](https://docs.akeyless.io/docs/pwm-mobile-installation).

## Same vault, built for touch

The mobile app is the same Password Manager you use in the
[web extension](https://docs.akeyless.io/docs/password-manager-web-extension): the same
Personal and Corporate areas, the same item types and the same create and edit forms. What
changes is how you reach things — a tab bar instead of a side rail, swipe gestures instead of
hover buttons, and bottom sheets instead of menus.
