Use the following steps to switch between the folder and flat list views in the extension.

## Switching Between Views in Personal and Corporate Areas

The extension provides two ways to view items in the Personal and Corporate areas.

## Flat View

Flat view shows items without folder nesting.

## Folder View

Folder view shows items within the folder hierarchy.

## Switching Between Views

To switch between the flat and folder views, follow these steps:

1. Navigate to the Flat View / Folder View icon located near the search field.
2. Select **Flat View** to display items without folder nesting.
3. Select **Folder View** to display the folder structure.
