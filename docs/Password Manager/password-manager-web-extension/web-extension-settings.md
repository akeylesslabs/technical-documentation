## Toggles

| Setting | Default | What it does |
|---|---|---|
| **Autofill** | Follows your account's `allowAutoFill` | Inserts login information automatically and offers credential suggestions. Your choice here overrides the account default from then on. |
| **Prompt to save password** | On | When you sign in with credentials that are not stored, the extension offers to save them. |
| **AI agent auto-fill** | Off | When an AI browser agent opens a sign-in page, fill the matching vault credential automatically. See [AI Agent Auto-fill](https://docs.akeyless.io/docs/web-extension-ai-agent-autofill). |
| **Passkey Management** | Off | Lets the extension manage passkeys. Hidden when your organization suppresses passkeys. |
| **Dark Mode** | Off | Switches to the dark theme. Hidden when organization branding is active. |

## File storage

Shows how much of your account's file quota you have used, with the remainder and a progress
bar. Visible only when password management is enabled on your account.
