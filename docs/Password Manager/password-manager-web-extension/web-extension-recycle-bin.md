Deleting an item does not destroy it. The item is tagged and moved out of the normal lists
into the Recycle Bin, where it can be restored or purged.

*Deleted items awaiting restore or purge*

## What you can do

| Action | Effect |
|---|---|
| **Restore** | Returns the item to its original folder |
| **Delete Forever** | Permanently removes one item |
| **Empty Recycle Bin** | Permanently removes everything |
| *`Search in recycle bin secrets`* | Filters the list |
| **Sort By A–Z** | Reorders; select the arrow to reverse |
| **Click to refresh** | Reloads from the vault |

Each row shows the item's original folder and its Personal or Corporate scope.

## Restoring several items at once

Select **Select**, tick the items, then choose **Restore** or **Delete**. A confirmation step
appears before anything is removed.

## Folders

Restoring a folder returns it together with the items it contained.

<Callout icon="⚠️" theme="warn">
  **Delete-protected items cannot be deleted at all.** They show a lock badge and never reach
  the Recycle Bin. Clear Delete protection on the item first.
</Callout>
