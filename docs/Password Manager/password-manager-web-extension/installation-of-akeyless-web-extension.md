## Download

Akeyless Password Manager 2.0 is a **separate listing** from the original Akeyless Password
Manager. Use these links rather than searching the store, so you land on the right extension.

| Browser | Minimum version | Install |
|---|---|---|
| **Google Chrome** | 88+ | [Add to Chrome](https://chromewebstore.google.com/detail/akeyless-password-manager/afmojeipcbpcfkdohnnjfkilfekoobmc) |
| **Microsoft Edge** | 88+ | [Get from Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/akeyless-password-manager/fppjjcloabbllcakfjefmkdpbaaikeog) |
| **Mozilla Firefox** | 91.1+ | [Add to Firefox](https://addons.mozilla.org/en-US/firefox/addon/akeyless-password-manager-2-0/) |
| **Safari** | — | Coming soon |

Running Akeyless Secrets Automation instead? Use the
[Akeyless SA 2.0](https://chromewebstore.google.com/detail/akeyless-sa-20/cdghndnnjccefelakphihcjngdokccpm)
listings — see *Secure Remote Access → SA Web Extension*.

## Install

1. Open the store link for your browser.
2. Select **Add to Chrome** / **Get** / **Add to Firefox**.
3. Review the requested permissions and confirm.
4. Pin the extension to the toolbar so it is one click away.

---

## Open the extension

Select the Akeyless icon in the toolbar to open the popup. To keep it beside the page while
you work, use the dock control at the bottom of the left rail:

- **Chrome and Edge** — *Pin to Side Panel*
- **Firefox** — *Open Sidebar*
- **Safari** — not available

## Installation types

| Type | What you get |
|---|---|
| **Store install** | The full login screen with every authentication method. |
| **Bridge link** | Your administrator sends a link carrying your organization's sign-in settings; the login screen arrives pre-filled. See [Bridge Link Install](https://docs.akeyless.io/docs/web-extension-bridge-link). |
| **Preconfigured package** | Your administrator distributes a package with the settings already inside. See [Preconfigured Package](https://docs.akeyless.io/docs/web-extension-preconfigured-package). |
