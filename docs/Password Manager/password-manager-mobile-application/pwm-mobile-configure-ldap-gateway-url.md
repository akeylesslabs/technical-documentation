Use these steps to configure the LDAP gateway URL for mobile sign-in.

![LDAP Gateway URL field in the mobile app settings](https://files.readme.io/006da13-Screenshot_2024-03-20_at_10.53.34.png)

## Step-by-Step Guide to Configuring Your LDAP Gateway URL in the Password Manager Application

1. Open the mobile app.
2. Open settings.
3. Open the LDAP gateway URL configuration field.

## Enter the LDAP Gateway URL

Enter the LDAP gateway URL provided by your administrator.

For administrator configuration guidance, see [LDAP Authentication Method configuration](https://docs.akeyless.io/docs/auth-with-ldap).

## Save Your Settings and Enter LDAP Credentials

![LDAP credentials entry screen in the mobile app](https://files.readme.io/921c299-Screenshot_2024-03-20_at_10.57.16.png)

1. Tap **Save**.
2. Continue to sign-in.
3. Enter LDAP credentials.
4. Confirm successful login.
