A native desktop app for macOS and Windows that gives you your Akeyless vault outside the
browser — with two things the Web Console cannot do: **Offline Mode**, so your personal
passwords are available with no network, and **Auto-Type**, which types credentials into any
application, not just web pages.

## Same vault, same screens

Everything you do with your vault works exactly as it does in the
[Web Console](https://docs.akeyless.io/docs/password-manager-web-console) — the same areas, the same views, the same
creation flows:

| Area | Covered in |
|---|---|
| Personal | [Personal Secrets](https://docs.akeyless.io/docs/pwm-console-personal-area) |
| Corporate | [Corporate Secrets](https://docs.akeyless.io/docs/pwm-console-corporate-area) |
| Favorites | [Favorites](https://docs.akeyless.io/docs/pwm-console-favorites) |
| Security Health | [Security Health](https://docs.akeyless.io/docs/pwm-console-security-health) |
| Recycle Bin | [Recycle Bin](https://docs.akeyless.io/docs/pwm-console-recycle-bin) |
| Cards, list, sort, filter, pagination | [Viewing Options](https://docs.akeyless.io/docs/pwm-console-view-options) |
| Creating items | [Creating Items](https://docs.akeyless.io/docs/pwm-console-creating-items) |
| Editing, sharing, deleting | [Editing, Sharing and Deleting Items](https://docs.akeyless.io/docs/pwm-console-editing-items) |
| Importing | [Importing from Another Password Manager](https://docs.akeyless.io/docs/pwm-console-import) |
