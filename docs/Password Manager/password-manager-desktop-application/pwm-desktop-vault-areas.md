---
title: Working With Your Vault on the Desktop
---
The vault areas behave exactly as they do in the
[Web Console](https://docs.akeyless.io/docs/password-manager-web-console) — same layout, same toolbar, same creation
flows. This page summarizes each area and links to its full documentation on the corresponding
Web Console page.

## The areas

### Personal

![Personal](https://files.readme.io/923eed04afdab3d20e0c8475ef27b6c72ebd2c79d3c4f6235551f33172f44248-personal-list.webp)

Items only you can see, including passkeys and files. The only area available in
[Offline Mode](https://docs.akeyless.io/docs/pwm-desktop-offline-mode).

→ [Personal Secrets](https://docs.akeyless.io/docs/pwm-console-personal-area)

### Corporate

![Corporate](https://files.readme.io/0900f6366bc65fdaf94ff348ddd5b453e87b8666cc9cecc0c62748990fbc6f50-corporate-list.webp)

Items shared across your organization, governed by your vault permissions. A **lock** badge
marks delete-protected folders.

→ [Corporate Secrets](https://docs.akeyless.io/docs/pwm-console-corporate-area)

### Favorites

![Favorites](https://files.readme.io/3e6ea2dfca4cf8f8aa41e5a677b6c932b75128d3769c615e8049a03ee8c608fa-favorites.webp)

Shortcuts drawn from both vaults at once. Stored with your account, so the same favorites
appear in the console and the browser extension.

→ [Favorites](https://docs.akeyless.io/docs/pwm-console-favorites)

### Security Health

![Security Health](https://files.readme.io/8a639d76f8e7d823a7d5128d27b187afc4170b0a219f1cf8e4e3e0f95ccc7777-security-health.webp)

A 0–100 score for your personal credentials, from password reuse, offline breach matching and
90-day freshness. Select a tile to list the items behind it.

→ [Security Health](https://docs.akeyless.io/docs/pwm-console-security-health)

### Recycle Bin

![Recycle Bin](https://files.readme.io/52812b99bc38227fde7f706b4fcc646eca97b74f9bc93f07aed205edd10c2281-recycle-bin.webp)

Deleted items from both vaults, restorable until purged.

→ [Recycle Bin](https://docs.akeyless.io/docs/pwm-console-recycle-bin)
