## CLI Agent

This section outlines the CLI commands relevant to CLI Agent.

<CLIGeneralFlags />

### `agent start`

Start Akeyless Agent

##### Usage

```shell
akeyless agent start
```

### `agent status`

Get Akeyless Agent status

##### Usage

```shell
akeyless agent status
```

### `agent stop`

Stop Akeyless Agent

##### Usage

```shell
akeyless agent stop
```
