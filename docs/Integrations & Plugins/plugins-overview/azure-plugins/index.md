Akeyless integrates with Azure DevOps in three different ways depending on your workflow and operational requirements.

* [Azure DevOps Extension](https://docs.akeyless.io/docs/akeyless-azure-devops-extension): The official Akeyless extension for Azure DevOps pipelines, including a dedicated service connection and tasks for authentication, static secrets, dynamic secrets, and rotated secrets.
* [Azure DevOps Plugin](https://docs.akeyless.io/docs/azure-devops-plugin): A HashiCorp Vault-compatible approach using the Vault Interaction task with the Akeyless HashiCorp Vault Proxy endpoint.
* [Azure DevOps Community Plugin](https://docs.akeyless.io/docs/azure-devops-community-plugin): A community-maintained option for teams that prefer or already use the community extension model.

For Azure identity-based authentication setup in Akeyless, see [Azure AD Authentication Method](https://docs.akeyless.io/docs/auth-with-azure).
