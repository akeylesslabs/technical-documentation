You can use AI agents in order to communicate with your resources in a secure connection. 

# Prerequisites

* [Akeyless Gateway](https://docs.akeyless.io/docs/gateway-overview) version `4.51.0`.
* CLI version `1.144.0`
* [AI Insights](https://docs.akeyless.io/docs/akeyless-ai-insight) enabled on the Gateway.
* An authentication method associated to a role that has Agentic Runtime Authority.
