The Certificates tab offers a clear overview of all certificates in your account. It displays a table with key details for each certificate, including:

- **Common Name**: The common name associated with the certificate.
- **Issuer**: The name of the Certificate Issuer that issued the certificate.
- **Status**: The current status of the certificate, such as Valid, Pending, About to Expire, Expired, or Revoked.
- **Expiration Date**: The date when the certificate will expire.

Additionally, this tab allows you to generate a new Certificate Signing Request (CSR) directly.
