The **Serverless Gateway** is a cloud-native solution that automatically scales with traffic, enabling developers to focus on application logic without managing infrastructure. It can be deployed on both **AWS** and **Azure** platforms.

* [AWS Serverless](https://docs.akeyless.io/docs/serverless-aws): The Serverless Gateway is implemented with AWS Lambda, which provides automatic scaling and high availability.

* [Azure Serverless](https://docs.akeyless.io/docs/azure-serverless): The Serverless Gateway is set up within a [Resource Group](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/manage-resource-groups-portal), a container for organizing resources like [Azure Functions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-overview?pivots=programming-language-csharp) and API Management, required for the application.

The following guides provide simple steps for setting up and running the Serverless Gateway on **AWS** and **Azure**.
