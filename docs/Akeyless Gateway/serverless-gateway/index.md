The **Serverless Gateway (GW)** is a cloud-native solution that automatically scales with traffic, enabling developers to focus on application logic without managing infrastructure. It can be deployed on both **AWS** and **Azure** platforms.

* [AWS Serverless](https://docs.akeyless.io/docs/serverless-aws): The Serverless GW is implemented with AWS [Lambda](https://aws.amazon.com/pm/lambda/?gclid=CjwKCAiAudG5BhAREiwAWMlSjMqGE01DsGOp0Zkk3AnNPEImhR-2eDyqjEs8-gburJEabB3z5_jo7BoCvmsQAvD_BwE\&trk=3da65280-58c3-4e9f-8d04-5402461fedce\&sc_channel=ps\&ef_id=CjwKCAiAudG5BhAREiwAWMlSjMqGE01DsGOp0Zkk3AnNPEImhR-2eDyqjEs8-gburJEabB3z5_jo7BoCvmsQAvD_BwE:G:s\&s_kwcid=AL!4422!3!651612444455!e!!g!!lambda%20aws!19836376555!148728891764), which provides automatic scaling and high availability.

* [Azure Serverless](https://docs.akeyless.io/docs/azure-serverless): The Serverless GW is set up within a [Resource Group](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/manage-resource-groups-portal), a container for organizing resources like [Azure Functions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-overview?pivots=programming-language-csharp) and API Management, required for the application.

The following guides provide simple steps for setting up and running the Serverless Gateway on **AWS** and **Azure**.
